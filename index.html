🚀 MarkdownFlow

¡Bienvenido a MarkdownFlow! Un visualizador de escritorio minimalista y libre de distracciones diseñado para convertir tus archivos Markdown en documentos PDF profesionales.

✨ Características Principales

  • Drag & Drop Nativo: Arrastra cualquier archivo .md directamente para cargarlo.
  • Imágenes Locales: Carga imágenes guardadas en tu disco de forma nativa.
  • Soporte GFM Completo: Tablas avanzadas, listas de tareas y citas.
  • Ecuaciones Matemáticas: Soporte total de notación científica mediante KaTeX.

🛠️ Uso Rápido

Para probar o desarrollar localmente el visualizador, clona el repositorio y ejecuta:

# Instala las dependencias del proyecto
npm install

# Inicia la aplicación en modo desarrollo
npm run dev

📋 Guía de Características

MarkdownFlow es compatible con el estándar GitHub Flavored Markdown (GFM) de alto rendimiento. A continuación se detallan las características del renderizador:

MarkdownFlow renderiza ecuaciones matemáticas complejas utilizando KaTeX en tus documentos. Puedes escribir fórmulas inline como E = mc² o bloques complejos.
